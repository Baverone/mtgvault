COMO ORGANIZAR AS FOTOS DA COLEÇÃO
==================================

Arrasta cada foto para a pasta certa:

DECKS ESPECÍFICOS (cartas que estão nesse deck):
  Blue Farm/
  Cloud Duel Commander/
  Cloud cEDH/
  Pauper Affinity/

GRUPOS:
  Premodern (geral)/                       -> qualquer carta dos decks de Premodern
  SPML (Standard Pioneer Modern Legacy)/   -> cartas destes formatos
  Coleção Pessoal/                         -> só tuas; NUNCA vão para venda nem
                                              para decks (no sistema: collector)

PARA VENDER:
  Vender/                                  -> cartas destinadas a venda

Podes fazer subpastas por lote dentro de qualquer uma (ex.: "lote1").

Depois diz-me: "processa as fotos novas".
Eu leio todas, identifico as cartas, atualizo o inventário e movo as fotos
para "Fotos processadas da coleção".

Nota: as IMAGENS não vão para o Git (ficam só no PC); as PASTAS sim, para
teres a mesma estrutura em qualquer PC.
