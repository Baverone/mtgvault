Cada deck é uma caixa. Esta é a página dos decks: a lista, o que falta comprar, o que tirar da coleção para o montar e o que sobra para vender. Uma cópia física entra numa caixa e só numa — quem conta é a alocação, não a coleção inteira (essa aparece como informação secundária em cada carta). Verde = está nesta caixa · âmbar = tens a carta mas não está aqui · vermelho = não tens nenhuma, é compra · ⚔ = partilhada com outra caixa. Dentro do âmbar há duas coisas diferentes, e a página diz sempre qual: 📦 em <caixa> — a cópia está mesmo sleevada lá dentro, vais àquela caixa buscá-la — e 🗂️ na Colecção, destinada a <caixa> — está na gaveta de sempre, só prometida por prioridade a uma caixa que ainda não está montada; essa podes tirá-la já, no passo 1 do painel Montar. Nenhuma das duas se compra. Os permanentes escolhem as cartas primeiro; uma candidata fica com o que sobrar. Quem manda é o colecao_config.json → caixas; para mexer nele com botões, corre python webapp.py no PC (porto 8771) — e aí a aba Plano dá-te um QR para abrires isto no telemóvel, à frente da estante. A lista para vender é uma sugestão a confirmar. Atualiza diariamente.
