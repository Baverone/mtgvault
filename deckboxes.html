Uma cópia física entra numa caixa e só numa — por isso os números aqui são mais baixos que os da página Decks permanentes, onde cada deck conta a coleção inteira. Verde = está nesta caixa · âmbar = tens a carta mas não está aqui (ou está noutra caixa — diz qual e quantas, vais lá buscá-la, não se compra — ou não serve esta caixa na língua/acabamento) · vermelho = não tens nenhuma, é compra · ⚔ = partilhada com outra caixa. Os permanentes escolhem as cartas primeiro; um candidato fica com o que sobrar. Quem manda no loadout é o colecao_config.json → loadout; para mexer nele com botões, corre python webapp.py no PC (porto 8771). A lista para vender é uma sugestão a confirmar. Atualiza diariamente.
